# Waveform evidence

The RTL and testbenches are provided for running in **Vivado → Run Behavioral Simulation**. This repository does not yet contain actual Vivado-exported waveform screenshots for every module. After running each testbench, use the waveform window's **Export Image** / screenshot option and save the genuine simulation evidence here as PNG files.

Suggested evidence filenames:
- `all_gates_waveform.png`
- `mux_2to1_waveform.png`
- `mux_32to1_waveform.png`
- `ripple_carry_adder_4bit_waveform.png`
- `sr_latch_waveform.png`
- `d_latch_waveform.png`
- `d_ff_waveform.png`
- `jk_ff_waveform.png`

Do not label hand-drawn or expected timing diagrams as real simulator captures.
